# AGENTS.md

Personal NixOS flake config.

## Commands

- Rebuild: `sudo nixos-rebuild switch --flake .#main-pc`
- Verify a change without applying: `nix flake check` and `sudo nixos-rebuild dry-build --flake .#main-pc`
- `nix flake update` only when the user asks to bump inputs. Note: `flake.lock` is currently root-owned, so updates/rebuilds that rewrite it need `sudo` (or `chown` it first).

No CI, linter, or formatter exists; verification is flake evaluation.

## Keeping this file current

When you change the repo, update `AGENTS.md` in the same session — it is the onboarding doc for future sessions:

- **Add**: new commands, gotchas, or conventions you had to discover or infer (e.g. a new `builtins.readFile` reference, a new host-specific quirk, a new pinned hash).
- **Update**: fix entries that no longer match the code (commands, paths, flake inputs, hardware notes).
- **Delete**: remove entries that became obsolete (renamed/removed files, resolved root-owned-lockfile notes, dropped conventions).

Keep it compact: only repo-specific, non-obvious facts; drop anything generic.

## Layout and conventions

- `flake.nix` is the source of truth for module imports. A new file in `modules/` does nothing until it is added to the `modules` list in `flake.nix` (or to a host module).
- `modules/` = one file per concern. Host-specific config lives in `modules/hosts/<host>/` (`main-pc`: NVIDIA drivers, Lofree keyboard modprobe fix, Thermalright TRCC app).
- `modules/hosts/main-pc/hardware.nix` is generated by `nixos-generate-config` — do not edit it; put changes in `modules/hosts/main-pc/default.nix` instead.
- Dotfiles are **not** managed by Nix. `scripts/dotf/dotf.sh` symlinks `dotfiles/<program>/` into `$HOME` and hardcodes `DOTFILES_DIR="$HOME/nixos-config/dotfiles"`. Run it with no args for usage; see README for examples.
- Some `scripts/` are embedded into the system via `builtins.readFile` (e.g. `suspend-mode.sh` in `modules/extras.nix`). Do not move/rename those without updating the reference.
- `scripts/toggle-speakers/` is standalone Python with a local `.venv` and a gitignored `.env` holding Tuya API secrets. Never commit `.env`.

## Gotchas

- `system.stateVersion = "26.05"` in `modules/configuration.nix` — do not change (commented in-file).
- `modules/extras.nix` pins `fetchurl` hashes (Notion icon, Viber `.deb`). Changing a URL requires updating its hash (use `nix-prefetch-url`).
- `allowUnfree` is enabled in `modules/apps.nix`; flake `nixConfig` adds the noctalia.cachix.org substituter.
- Hardware context: AMD Ryzen 5 7500F + RTX 5060 Ti (explains `hardware.nvidia.open`), Thermalright cooler (explains the trcc-linux module).
