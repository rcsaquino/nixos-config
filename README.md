## Layout

```
.
├── flake.nix                 # Entry point, pins nixpkgs & noctalia inputs
├── modules/
│   ├── configuration.nix     # System config: boot, user, packages, services
│   ├── hardware.nix          # Generated by nixos-generate-config
│   └── noctalia.nix          # niri compositor + noctalia-greeter
├── dotfiles/                 # Per-app dotfiles, symlinked into $HOME
│   ├── alacritty/  fish/  ghostty/  mangohud/  mpv/
│   ├── nautilus/   niri/  noctalia/ paru/      zed/  zsh/
├── assets/                   # Icons, wallpapers, odin & zig toolchains
├── scripts/
│   └── toggle-speakers       # Audio output switcher
└── AGENTS.md
```

## Usage

Rebuild the system:

```sh
sudo nixos-rebuild switch --flake .#main-pc
```

Rebuild and commit the resulting lockfile:

```sh
sudo nixos-rebuild switch --flake .#main-pc --commit-lock-file
```

## Key configuration

- **Boot**: systemd-boot, latest stable kernel (`linuxPackages_latest`)
- **GPU**: NVIDIA (open kernel modules) via `services.xserver.videoDrivers = [ "nvidia" ]`
- **User**: `rcsaquino` with fish shell, wheel group
- **Shell tools**: zoxide (fish integration), git, nix-ld
- **Packages**: alacritty, ghostty, zed-editor, google-chrome, nautilus, odin, zig, uv, rustup, nil, nixd, nixfmt, opencode
- **Compositor**: [noctalia](https://github.com/noctalia-dev/noctalia) (niri-based) with noctalia-greeter
- **Time zone**: Asia/Manila

## Dotfiles

Dotfiles live in `dotfiles/<app>/` mirroring their `$HOME` layout (e.g. `dotfiles/fish/.config/fish/`). Install a whole app with a recursive symlink:

```sh
ln -s "$(pwd)/dotfiles/fish/.config/fish" ~/.config/fish
```
